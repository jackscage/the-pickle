## The specification

The full specification lives in Google Drive, in the folder "The Pickle":

| Document | What it is |
| --- | --- |
| PROJECT_SPEC.md | Master product and technical specification, 28 sections |
| BUILD_JOURNAL.md | Running history of decisions and what got built |
| GLOSSARY.md | Plain-English reference for every technical term used |
| TECHNICAL_RESEARCH.md | Research findings, with sources |
| SESSION_04_DECISIONS.md | Decisions made and pending spec amendments |
| SESSION_05_DECISIONS.md | Phases 2–5, the deployment, and what the build taught |

The claude.ai Project "Pickle Jar App" also carries `PROJECT_STATE.md` (where
the project stands, read first by any new session), `NEXT_SESSION.md` (what to
do next), and `LEARNING_NOTES.md` (the running explanation of what was built
and why, for the eventual full guide).

## Which copy is authoritative

Google Drive, for the specification. The claude.ai Project holds a mirror of
the spec that is cheaper for a session to read, and the state documents that
only make sense there.

Anything in this repository describes the code. Where the two disagree about
what the code does, the repository is right and the spec needs amending —
that has happened twice already, and both times the spec was the thing that
was wrong.
